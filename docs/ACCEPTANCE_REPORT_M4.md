运行结果：`py -3.12 -m unittest discover -s tests -v` 为 16 项通过（含实际 OS 子进程的去重、停用、重启检查）；JDK 21 容器内 `mvn -q test` 为 21 项通过。`docker compose --profile monitor config --quiet` 与监控镜像构建通过。新内部接口在运行中的 Spring 容器返回启用 UP、固定路由及扫描状态，状态更新成功；Nginx 继续隐藏 `/internal`。

真实 B 站联调使用本机 Git 忽略的 `deploy/.env`，未输出或提交 Cookie。测试 UID `550494308` 的空间接口返回 50 条；动态 `1251460007328743432` 的作者、充电文字/图片类型、评论目标 `410108956` / `11` 均验证通过。根评论接口 `page.count` 含楼中楼，因此扫描器按实际根评论页结束。完整读取 349 条评论，4 批入库；MySQL 查询为 1 条动态、349 条评论、350 条已就绪事件。重扫新增事件 0；增量状态建立后下一轮没有不必要的楼中楼请求。期间没有飞书发送。

监控容器短暂运行时只有 1 个 UP 子进程（另有 Python 资源跟踪进程），随后正常停止；MySQL、Spring、Nginx 继续健康运行。首次运行曾发现普通视频动态的可选角标为 `null`，修复后真实空间最新 50 条全部解析成功，重新启动和停止监控容器没有报错。

## 1. 页面与权限

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| UI-01 | 未登录访问动态列表、详情、图片和管理接口 | 均被拒绝；只有登录接口可用 |

## 2. 配置与数据约束

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| CFG-01 | 新建两个命名飞书群，在不同 UP 中复用 | 选择同一群 ID，不需重复输入 Webhook；列表不显示明文 URL |
| CFG-02 | 尝试删除被运维、默认或专属路由引用的群 | 返回 409 并显示引用位置；解除引用后可删除 |
| CFG-03 | 用 UID 和空间 URL 分别预览并添加 UP | 预览返回相同 UID/资料；保存后默认启用 |
| CFG-04 | 添加 UP 时缺运维群、缺两个默认群、或两个默认群相同 | 每种情况均拒绝，数据库 CHECK/外键也阻止绕过页面写入 |
| CFG-05 | 给 UP 添加专属动态：有效、他人动态、非充电、非文字图片 | 只接受属于该 UP 且范围内的动态；有效配置可先于内容入库 |
| CFG-06 | 专属动态路由两群都空或两群相同 | 保存失败；至少一群且互异时保存成功 |
| CFG-07 | 删除专属路由 | 该动态以后走 UP 默认路由；若已跌出最新 50 则不再固定扫描；已存内容不删除 |
| CFG-08 | 查看 UP 状态页 | 显示最近成功扫描、最近错误、待发送数；无手动重扫/重发按钮 |

## 3. 抓取、内容与图片

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| CRAWL-01 | 模拟 UP 空间 51 条动态，第 1～50 条混合内容 | 只对取到的前 50 条筛选充电文字/图片；第 51 条不因“筛后不足 50”被补取 |
| CRAWL-02 | 为第 51 条合格动态配置专属路由 | 作为固定目标单独抓取并显示；同一动态在最新 50 与固定目标同时出现时只入库一次 |
| CRAWL-03 | 新增 UP 首次发现若干现存动态与评论 | 全部合格内容入库，按有效路由入队可投递的动态/评论通知；不静默略过基线 |
| CRAWL-04 | 停用 UP，模拟新增超过 50 条，重新启用 | 只抓当时最新 50 条和固定目标；超出窗口的普通动态不回溯，既有队列恢复发送 |
| CRAWL-05 | 更新已存动态或评论文字 | 网站展示最新抓到的版本，不新增飞书编辑事件 |
| CRAWL-06 | 动态跌出最新 50、B 站请求超时、明确返回来源不可用 | 前两者不误标删除；只有明确证据才标记来源不可用 |
| CRAWL-07 | 完整评论校准成功时缺少旧评论；分页中途失败时缺少旧评论 | 只有完整成功的校准可标记评论来源不可用 |
| CRAWL-08 | B 站图片或 OSS 暂时失败，然后恢复 | 文字立即可见，图片有占位；后台重试成功后变为可看 |
| CRAWL-09 | 直接匿名请求私有 OSS 原 URL、登录后请求本站图片接口 | 前者被拒绝；后者获得短效签名访问，过期后重新请求本站路径可再看 |
| CRAWL-10 | 用作者 UID 对比 UP UID 检测 UP 回复 | UP 自己的根评论和楼中楼均被标为 UP，本人以外不误判 |

## 4. 飞书路由与故障恢复

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| MSG-01 | 默认路由同时配置甲（全部）与乙（UP），发现新动态 | 动态概览分别发甲、乙；普通评论只发甲；UP 评论发甲、乙 |
| MSG-02 | 对该动态配置专属丙（全部）与丁（UP） | 后续事件只按丙、丁路由，不再按甲、乙 |
| MSG-03 | 旧事件已全部送达后新建专属路由 | 不补发该动态及其已处理评论 |
| MSG-04 | 一条事件的甲目标成功、乙目标尚未成功时改路由 | 甲不重发；未发目标使用新的有效群，投递记录保留实际发送群名 |
| MSG-05 | 连续发生同一种抓取错误并跨过整点 | 每轮向该 UP 运维群报错，每小时向其运维群报正常心跳；全局故障仅在服务器日志 |
| MSG-06 | 飞书失败后恢复 | 按 5/10/15/30/60 秒阶梯重试，同群后续消息不越过未完成队头 |
| MSG-07 | 在批次写入中制造数据库失败，然后重试同批次 | 内容、扫描进度、通知事件一起回滚；重试后各只有一份 |
| MSG-08 | 飞书成功后、写成功状态前杀死进程 | 租约到期后可重试；允许该极端场景重复一条，不允许直接丢弃 |
| MSG-09 | 查看/清理成功投递记录 | 成功记录保留 90 天；待发和失败记录不按 90 天清理 |
| MSG-10 | 在测试群发送带图片的动态与评论通知，并使飞书图片上传暂时失败 | 文字与图片按现有消息格式发送；图片上传失败进入通知重试，不影响本站 OSS 图片任务 |

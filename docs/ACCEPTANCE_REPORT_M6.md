# M6 图片与私有 OSS 验收记录

- 日期：2026-09-27
- 范围：图片后台任务、私有 OSS、登录后签名访问、`CRAWL-08～09` 与 `UI-07` 的 READY 图片部分
- 环境：本地 Docker Compose、MySQL 8.4.11、Spring Boot 3.5.16 / JDK 21、真实 B 站图片 CDN、用户配置的阿里云私有测试 Bucket

## 实施内容

Spring 后台任务分别处理动态和评论图片。下载仅接受 B 站图片 CDN 域名，禁止重定向并限制 20 MiB；旧扫描快照中的 `http://` 来源改用 HTTPS 获取。下载和 OSS 上传在数据库事务外，成功设为 READY 并记录对象 Key；失败保留文字和图片占位，按次数退避重试。来源明确返回 410 或地址无效时设为 UNAVAILABLE。V3 数据库迁移增加尝试次数，状态更新校验来源 URL 与次数，避免旧任务覆盖新来源。

本站媒体路径需要管理员会话。READY 时签发 10 分钟 HTTPS GET URL 并返回 302，不缓存跳转；PENDING/RETRY 返回 409，UNAVAILABLE 返回 410。前端在图片未就绪时显示占位并刷新状态，READY 图片加载失败时可再次尝试本站路径。头像继续使用来源 URL。

| 服务状态 | 本地 Compose 的 `mysql8`、`spring-app`、`nginx` 均为 healthy；监控容器在图片验收期间停用，避免额外扫描 |
